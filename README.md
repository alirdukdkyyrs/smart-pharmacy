# نظام إدارة الصيدليات الذكي

مشروع ويب أولي قابل للتشغيل باستخدام Python وDjango وSQLite، بواجهة عربية RTL.

## التشغيل على Windows 10
1. ثبّت Python 3.11 أو أحدث.
2. افتح مجلد المشروع في VS Code أو Terminal.
3. أنشئ بيئة افتراضية:
   `python -m venv venv`
4. فعّلها:
   `venv\\Scripts\\activate`
5. ثبّت المتطلبات:
   `pip install -r requirements.txt`
6. أنشئ الجداول:
   `python manage.py migrate`
7. أنشئ مستخدم المدير:
   `python manage.py createsuperuser`
8. شغّل الموقع:
   `python manage.py runserver`
9. افتح:
   `http://127.0.0.1:8000/`

## الوظائف الموجودة
- تسجيل الدخول والخروج.
- لوحة تحكم وإحصائيات.
- إضافة وتعديل وحذف الأدوية.
- البحث في الأدوية.
- تنبيه المخزون المنخفض وقرب/انتهاء الصلاحية.
- إنشاء فاتورة بيع وتحديث المخزون تلقائياً.
- عرض سجل المبيعات.
- لوحة Django Admin لإدارة البيانات.
